# Study Overview

This directory aggregates the results from all three planned experiments.

## Runs

- `run1_core_full`: Run 1 Core Two-Agent Handoff (run1_core, 50 tasks)
- `run2_multihop_subset15`: Run 2 Multi-Hop Extension (run2_multihop, 15 tasks)
- `run3_ablation_full`: Run 3 Prompt-Only Ablation (run3_ablation, 50 tasks)
